# Feature map index (template)

> Replace this with maps generated by pstack `/create-verification-skill` or hand-written entries for your product.

## How to use

Each feature file should tell an agent:

1. **User-facing name** and what it does
2. **How to get there** (nav path, URL, keyboard shortcut)
3. **Selectors** for automation (test IDs, CDP-friendly attributes)
4. **Sub-features** and known footguns
5. **Related code directory** (colocated feature folder)

## Suggested layout

```text
features/
  README.md          ← this index
  onboarding.md      ← example stub
  settings-export.md ← example stub
```

## Stub entry (copy)

```markdown
# Feature: <NAME>

- Path: <UI steps>
- Shortcut: <if any>
- Selectors: <data-testid / aria>
- Code: <path/to/feature>
- Verify: <finish condition>
```

## Maintenance

`/maintain-verification-skill` should update these files when the product changes — **without** editing product source.
